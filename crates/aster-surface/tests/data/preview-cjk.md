# 中日文预览样张

排版引擎需要处理“禁则”：句号、逗号和后引号（」』）》等）不能出现在行首，前引号（「『（《等）不能出现在行尾。连续的标点，例如“」，「”或者“）。”，中间的空白应当被挤压，否则版面会显得松散。Aster Office 使用 Rust 1.95 和 Slint 1.19 开发，中文与 English 之间会自动留出四分之一个字的空隙。

日本語の組版では、行頭に句読点や閉じ括弧（」）、小書きの仮名（ゃ・ゅ・ょ・っ）、長音記号「ー」などを置くことはできません。これを「行頭禁則」と呼びます。コンピューターでチェックしましょう。

强调的写法：*这是一段强调的中文*，**这是加粗的中文**，*日本語の強調*，以及 *English emphasis* 和 ***粗斜体***。
