### Markdown

- 打开和保存：
  - UTF-8，以及 GB18030、Big5、Shift_JIS、EUC-JP、EUC-KR、Windows-1252、带 BOM 的 UTF-16，保存时写回原来的编码。
  - 崩溃恢复，100 MB 的文件也能编辑。
  - 察觉文件在外面被修改。
- 显示：语法高亮，预览和左右分屏，代码块按语言着色（21 种语言）。
- 编辑：
  - 查找替换（含正则）。
  - 格式工具栏和格式菜单。
  - 列表续写、缩进和自动编号；表格编辑；任务框在预览里点击勾选；括号自动补全；脚注；目录；标题锚点。
- 图片：本机图片显示，网络图片不加载；粘贴截图会存成文件。
- 导出：HTML 和 PDF（文字可搜索、链接可点、有书签，纸张按地区选 A4 或 Letter）。
- 侧栏：文件树和最近列表，新建、改名、移到废纸篓，大纲。

### Excel

- 显示：单元格样式、冻结窗格、图片、主题色、数字格式，日期列宽按 Excel 的规则算。
- 编辑：
  - 输入（含中文输入法），公式增量重算，定义名参与计算。
  - 复制粘贴（和其他程序互通，公式引用随位置移动），撤销重做。
  - 格式工具栏：字体、颜色面板、填充、边框、合并、对齐、换行、自动求和；整行整列格式。
  - 结构：插入和删除行列（公式、定义名、条件格式、数据验证跟着移动），隐藏和取消隐藏，拖动边线改行高列宽。
  - 工作表：增加、改名、删除、拖动排序，复制和移动（“移动或复制”对话框，复制后公式指向副本自己的单元格）。
  - 排序（升序、降序）和自动筛选。
  - 批注：插入、编辑、删除，排序和插入删除行列时跟着移动；Excel 的会话式批注只读，原样保存。
  - 数据验证的下拉列表：箭头或 Alt+↓ 选值；规则是“停止”时拒绝列表以外的值。其他验证类型只保留不检查。
  - 填充柄，查找替换，冻结窗格的设置（视图菜单）。
- 保存：
  - 只重写改动的部分，其余部件逐字节不变。
  - 输入日期、百分比、金额时自动套格式，必要时往 styles.xml 追加格式（用户 2026-11-24 同意）。
  - 新建工作簿；崩溃恢复（写入间隔随工作簿大小自适应）。
- 不支持插入和删除行列的情形（批注、Excel 表、数据透视表等）会用通俗的话说明原因。

### Writer（Word 文档）

2026-11-26 开始做，同一天合并。四个 crate：`aster-writer`（文档模型和编辑操作）、`aster-ooxml` 里的 DOCX 读取和保存、`aster-layout`（分页排版）、`aster-surface` 里的文档视图。

- 打开：.docx 和 .docm（宏不读也不运行）。
  - 段落和文字格式、样式、多级列表（含中文、日文编号）、表格（合并单元格、边框、底纹、嵌套）、分节、页眉页脚和页码、脚注尾注、图片、文本框、注音。
  - 修订显示为接受以后的样子，批注不显示，两者都原样留在文件里。
- 排版：分页、分栏、横竖页面混排、文档网格、首行缩进、制表位和前导符、孤行控制、表头行重复、表格行跨页。文档指定的字体本机没有时，行高按该字体的比例算，不按替代字体算。
- 编辑：只能改正文和表格里的文字。
  - 输入、删除、分段、剪切复制粘贴、撤销重做、查找替换。
  - 粗体、斜体、下划线、删除线、字体、字号、文字颜色、高亮、对齐、缩进、行距、项目符号和编号、段落样式。
- 保存：没改的段落逐字节不变，改了的段落只重写改了的文字片段；书签、批注范围、域代码、修订里删掉的文字留在原位。不做修改直接保存，整个文件逐字节不变。新建空白文档；崩溃恢复。
- 检验用的真实文件：Apache POI、pandoc、python-docx、LibreOffice 四个项目的测试数据，共 399 个，不进仓库。
  - 读取和排版：382 个成功，17 个是加密或损坏的文件，被正确拒绝；没有崩溃或卡死。
  - 页数：275 个文件自带页数记录，255 个和排出来的一致。两份长文档还多出 5% 到 10%，原因没找到。
  - 保存：每个文件做一组编辑后保存，都能读回，macOS 自带的导入器也能打开，文字没有丢。
- 还没有：
  - 插入表格、图片、链接，增删表格的行列；
  - 改页眉页脚、脚注、文本框里的文字；
  - 文字绕着图片排（现在从图片下面继续）、竖排、分栏的两栏对齐；
  - 图表和 SmartArt 只显示占位框；
  - 修订标记和批注的显示；
  - 打印和导出 PDF；
  - AI 助手只能读 Word 文档，不能改。
- 各项简化写在 [`crates/aster-layout/README.md`](../crates/aster-layout/README.md) 和 `crates/aster-shell/README.md` 的 Writer 一节。

### PDF

- 查看：翻页、缩放（适合宽度、适合页面）、缩略图条，加密文件问密码。渲染用 hayro 0.9。
- 安全：
  - 打开前在 hayro 解析好的对象上检查每个流，不认识的一律拒绝；
  - 解析和渲染放在子进程里，所有 PDF 子进程共用一个内存总额度（3 GB 和本机内存四分之一里取小的），同时最多 2 个；
  - 打开限 60 秒，每页限 20 秒，每页最多 1600 万像素；
  - 应用进程里每个视图的像素最多 256 MB；
  - macOS 上子进程在沙盒里：不能联网、不能写文件、不能启动进程，只能读系统字体。
- 经过三轮独立安全审查（2026-11-24、11-25 两次），发现的问题都修了，每条都有回归测试。威胁模型和兜不住的部分（字体、着色等解码器内部，Linux 和 Windows 上没有沙盒）写在 `crates/aster-shell/README.md` 的 PDF 一节。
- 大纲、文字选择和复制、查找（`1c79cde`）。
- 还没有：超过 1600 万像素的页面会发虚（要做分块渲染）。

## 工作方法

- 主会话负责计划和验收，实现交给子 agent。每个分支先变基到 main，跑通 `scripts/ci.sh`，复核以后快进合并；能在窗口里试的，攒成一批一起试。
- 复核别的分支时，在单独的 worktree 里用它自己的 `target/`。不要和别的检出共用 `CARGO_TARGET_DIR`：Cargo 会把同名的工作区 crate 混在一起，报出假错误。
- 测试版本用 `ASTER_DATA_DIR` 指到临时目录，免得测试文件进用户的最近列表；用 `spikes/bundle-macos.sh` 包成 .app 时换一个名字，避免和别的会话的测试版本撞 bundle id。
- 后台注入的输入会丢掉 Cmd 键、点击可能送两次。要确认快捷键和拖动，用界面测试或真实键鼠。
